# To Do list

## Project overview 

This to do list application is a simple webpage meant to store todo Items and mark off weather they are done or not.
This is meant to improve the Developers skills with Node, React, Supabase, databases, and containerization.



Requriments: 

User must be able to:
	1. Log-in to a secure account 
	2. Create a to do list linked to the current date
	3. Add items to the to do list
	4. Check off to do items as they are completed
	5. Save to do list items
	6. Copy old to do list items to be in the next list.


Stretch requirements
	1. Share Goals and finished lists with other accounts on a feed.
	3. Create Private and public and friends only lists
	2. Comment on public lists
